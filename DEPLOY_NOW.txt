   app.py

5. Commit to branch: main
6. Go to https://share.streamlit.io/
7. Create app with:
   Repository: your new repo
   Branch: main
   Main file path: app.py
8. Click Deploy and keep the app logs open if an error appears.

NEW FEATURES
- Admin: create hotspot advisory, area, severity, precautions, source, expiry, optional map coordinates.
- Clicking publish stores the advisory and queues persistent in-app notifications for Citizens in that area; 'All Areas' broadcasts to all active Citizen accounts.
- Closing an advisory with a reason creates citizen closure-update notifications.
- Field Officer: type a structured site-investigation report and attach site evidence.
- PDFs: Citizens can download their own case PDF; Field Officers can download investigation PDFs; Admins and permitted Representatives can download permitted investigation reports.
- Case assignment and operational status changes also create in-app messages.
